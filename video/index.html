Watch FD-NL2SQL in action

This demo walks through the clinician-facing FD-NL2SQL workflow, showing how the system interprets oncology evidence questions, retrieves relevant exemplars, generates executable SQL, and returns auditable trial results in a transparent interface.

What this demo covers

  • The front facing interface for the clinician to query for oncology trials.
  • The chat interface to make natural queries to retrieve the trials.
  • The mechanisms to provide feedback for the system to draw from past queries.
